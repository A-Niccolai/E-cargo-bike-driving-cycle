# Florence cargo bike driving cycle (FCBDC)

This repository contains the driving cycle developed for e-cargo bikes based on real-world riding data collected in Florence, Italy. The cycle was generated using a Markov Chain Monte Carlo (MCMC) model from 50 km of naturalistic data collected by four riders along a typical postal delivery route (in collaboration with Poste Italiane), using an instrumented BCARGO Professional e-cargo bike equipped with a GPS/accelerometer data logger. The cycle lasts 1641 s, covers 3.96 km, with a maximum speed of 26.1 km/h, and closely reproduces the dynamic riding characteristics observed in the real-world data (SAPD error of 2.1%).
The DC is availablea as .mat in the file E-cargo_bike_DC or .txt

The cycle can be useful for powertrain sizing, range estimation, and energy consumption assessment of pedal-assisted vehicles for urban logistics.

For more details on the methodology, please refer to the paper:

Niccolai, A.; Raimondi, A.; Berzi, L.; Baldanzini, N. Investigation of User Behavior in Pedal-Assisted Vehicles: From Field Testing to Driving Cycle. Eng. Proc. 2026, 131, 18. https://doi.org/10.3390/engproc2026131018
